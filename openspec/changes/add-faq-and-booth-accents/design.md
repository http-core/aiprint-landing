## Context

См. proposal.md. Источник фирменного языка — интерфейс будки (`aiprint_server/booth`): Unbounded, `#E6FF30`, `#FE511E`, тёмные экраны, пиксельные иконки. Пользователь попросил не копировать его 1 в 1: сайт для покупателей оборудования.

## Goals / Non-Goals

**Goals:** узнаваемость бренда будки на лендинге; ответы на возражения покупателя; ноль новых JS для FAQ.

**Non-Goals:** детская подача интерфейса будки (сплошные паттерны, мемы, персонажи); блоки «экономика», «было → стало», галерея (не выбраны); замена портретов — пользователь готовит собственную серию.

## Decisions

- **FAQ на `<details>/<summary>`** — нативная доступность и работа без JS; плавность — CSS (`::details-content` / `interpolate-size` там, где поддерживается, иначе мгновенно). Альтернатива (кнопки + aria-expanded + JS) — больше кода без выигрыша.
- **Unbounded только для заголовков** (h1–h3, название модели). Шрифт широкий — кегли уменьшены ~на 15%, трекинг ослаблен. Onest остаётся для текста, Playfair italic — для одного акцентного слова, JetBrains Mono — для служебных подписей.
- **Акценты будки:** `--lime → #E6FF30` (кнопки-иконки, чипы цены, выделение выбранного), `--coral → #FE511E` (точки-маркеры, hover); для текста — тёмные варианты с контрастом ≥ 4.5:1. Фиолетовый остаётся (в будке — фон-градиент).
- **Тёмная сцена «Оборудование»**: `#0E0E0E`, паттерн — собственный SVG-тайл пиксельной молнии (≈ 1 КБ) с opacity ~6% вместо 2.5k×2k PNG из будки. Карточка модели остаётся белой — «экран» на тёмном фоне.
- **Пиксельные детали — ровно две:** курсор у главной кнопки hero (PNG из будки, `image-rendering: pixelated`), пиксельные искры у выбранного варианта. Без анимаций ради анимаций.

- **Производительность шрифта:** Unbounded предзагружается (иначе подмена шрифта в h1 сдвигает объектив, CLS 0.06), латиница урезана `scripts/subset-fonts.sh`, стили встроены в HTML (`build.inlineStylesheets: 'always'`), надпись на объективе — системным моноширинным шрифтом. Lighthouse mobile: Performance 85, A11y 100, CLS 0.006.

## Risks / Trade-offs

- [Unbounded шире Onest — переполнение крупных заголовков на 320px] → кегли через clamp, проверка e2e «нет горизонтального переполнения».
- [Тёмная секция между светлыми ломает ритм] → переходы без резких швов: секция начинается после отступа, рамка из сцены печати остаётся на светлом фоне выше.
- [Safari 18] → `::details-content` не поддерживается — деградирует до мгновенного раскрытия; прогон `npm run test:safari18`.
